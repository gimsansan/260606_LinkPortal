# 링크함 — 사용 설명서

웹 링크를 폴더로 모아 두고, **더블클릭**으로 바로 여는 **데스크톱용 앱**입니다.  
설치·회원가입 없이 브라우저에서 쓰며, **내 PC에만** 데이터가 저장됩니다.

---

## 3분 만에 시작하기

```
  ① 앱을 연다          ② 링크를 넣는다              ③ 더블클릭으로 연다
 ┌──────────┐      ┌──────────────┐            ┌──────────┐
 │ 🧺 링크   │  →   │ .url 파일을   │       →    │  카드     │
 │   바구니  │      │ 끌어다 놓기   │            │ 더블클릭  │
 └──────────┘      └──────────────┘            └──────────┘
```

1. **링크함**을 열면 **`🧺 링크 바구니`** 가 선택됩니다.
2. 바탕화면 **`.url` 바로가기**를 앱 위에 **끌어다 놓습니다.** (아래 [드래그 앤 드롭](#-드래그-앤-드롭으로-링크-넣기) 참고)
3. 생긴 **카드를 더블클릭**하면 해당 사이트가 열립니다.

## 화면 구성

```
┌─────────────────────────────────────────────────────────┐
│  링크함    [전역 검색]           🔍  ⬇  ⬆  🌙/☀️/✨   │  ← 헤더
├──────────────┬──────────────────────────────────────────┤
│   폴더  [+]  │  (선택한 폴더)                   +  ▶   │
│   🧺 링크 바구니│  [검색]  정렬  랜덤 재생  자동 넘김 …               │
│   🧺 새 폴더  │  ┌────┐ ┌────┐ ┌────┐                   │
│   └ …        │  │카드│ │카드│ │카드│                     │
└──────────────┴──────────────────────────────────────────┘
   왼쪽: 폴더 트리                 오른쪽: 링크 카드
```

| 버튼 | 기능 |
|------|------|
| **링크함** | **홈**(링크 바구니)으로 이동. 검색·YouTube 재생도 끔 |
| **🔍** | 모든 폴더에서 링크 검색 |
| **⬇ / ⬆** | 데이터 백업 / 복원 |
| **🌙 ☀️ ✨** | 테마 변경 (다크 · 라이트 · 네온) |

**링크 바구니** — 새로 모은 링크를 잠깐 두는 곳입니다. 정리할 때 다른 폴더로 옮기면 됩니다.

## 🖱️ 드래그 앤 드롭으로 링크 넣기

가장 빠른 방법입니다. **바탕화면 `.url` 파일**이나 **브라우저 탭·주소창의 URL**을 앱 **아무 곳**에 놓으세요.

### Step 1 — 파일 고르기

```
  🖥️ 바탕화면
 ┌─────────────────────┐
 │                     │
 │   📄 naver.url      │  ← Ctrl+클릭으로
 │   📄 google.url     │    여러 개 선택 가능
 │                     │
 └─────────────────────┘
```

### Step 2 — 앱으로 끌어오기

```
  🖥️ 바탕화면                           🌐 링크함
 ┌──────────┐                    ┌──────────────────────────┐
 │          │                    │  링크함  🔍       🌙     │
 │ 📄 naver │ ──── 드래그 ───▶  ├────────┬─────────────────┤
 │ 📄 google│                    │ 폴더   │ 🧺 링크 바구니  │
 │          │                    │ ├ 🧺   │                 │
 └──────────┘                    │ └ …    │   여기에 놓기!   │
                                 │        │       ⬇         │
                                 └────────┴─────────────────┘
```

- 드래그하는 동안 **반투명 오버레이**와 *「.url 파일 또는 링크를 놓으세요」* 문구가 보입니다.
- **폴더를 먼저 클릭**해 두고 놓으면 → **그 폴더**에 추가
- 폴더를 고르지 않았으면 → **`🧺 링크 바구니`** (없으면 자동 생성)

### Step 3 — 카드가 만들어짐

```
  ✅ 완료!

  🧺 링크 바구니
 ┌──────────────────────────────────────────┐
 │  ┌─────────────┐   ┌─────────────────┐  │
 │  │ 🌐          │   │ 🔍              │  │
 │  │  NAVER      │   │  Google         │  │
 │  │  naver.com  │   │  google.com     │  │
 │  └─────────────┘   └─────────────────┘  │
 └──────────────────────────────────────────┘
```

제목·썸네일은 URL에서 **자동으로** 가져옵니다. (YouTube는 채널명도 표시)

### 한눈에 보기

```
  📄 naver.url  ─┐
                  ├── 드래그 ──▶  🌐 링크함  ──▶  🃏 카드 생성 + 해당 폴더로 이동
  📄 google.url ─┘              (아무 곳)
```

| 넣을 수 있는 것 | 방법 |
|----------------|------|
| Windows `.url` 바로가기 | 탐색기·바탕화면에서 끌기 |
| 브라우저 URL | 주소창·탭에서 끌기 |
| 여러 개 | `.url` 여러 파일 또는 URL 여러 개 |

## + 버튼으로 링크 넣기

1. 왼쪽에서 **폴더 선택**
2. 오른쪽 위 **+** 클릭
3. URL 입력 (`naver.com`만 써도 됨) → **추가**

**제목 수동 입력**을 켜면 썸네일 없이 제목만 직접 정할 수 있습니다.

## 링크 열기

| 동작 | 결과 |
|------|------|
| 카드 **더블클릭** | 사이트 열기 |
| 선택 후 **Enter** | 사이트 열기 |
| **YouTube** | 앱 **안에서** 재생 |
| **그 외** | **새 탭**에서 열기 |

**YouTube**

- **▶ 전체 재생** — 폴더 안 YouTube를 연속 재생 (기본: **최근 추가순**)
- **랜덤 재생** — 툴바 토글. 켜면 다음 곡·전체 재생 순서가 **랜덤** (끄면 최근 추가순)
- **자동 넘김** — 영상이 끝나면 다음으로 (툴바에서 ON/OFF)
- 재생이 안 되면 새 탭으로 열림 · **×** 또는 바깥 클릭으로 닫기

> **재생 순서 vs 목록 정렬** — 카드 **목록**의 「최근 추가순 / 이름순」은 **화면 표시**용입니다. YouTube **재생·다음 곡** 순서는 별도로, **최근 추가순**(또는 랜덤 재생 ON)을 따릅니다. 이름순으로 바꿔도 재생 순서는 바뀌지 않습니다.

## 폴더 다루기

| 하고 싶은 일 | 방법 |
|--------------|------|
| 폴더 열기 | 트리에서 **클릭** |
| 새 폴더 (맨 위) | 「폴더」 옆 **+** |
| 하위 폴더 | **⋯** → **📁 하위 폴더 추가** |
| 이름 바꾸기 | 폴더 **더블클릭** |
| 위치 옮기기 | **⋯** → **↗ 이동** |
| 삭제 | **⋯** → **❌ 삭제** (안의 링크·하위 폴더 모두 삭제) |
| 접기 / 펼치기 | **▸ / ▾** |

> 폴더는 드래그로 옮길 수 **없습니다.** ⋯ 메뉴의 **이동**을 사용하세요.

## 링크 정리하기

### 다른 폴더로 옮기기

- 카드 **↗** 버튼 → 폴더 선택
- 카드를 **왼쪽 트리의 폴더** 위에 끌어다 놓기

```
  오른쪽 카드              왼쪽 폴더
 ┌────────┐
 │ NAVER  │ ──드래그──▶  🧺 새 폴더
 └────────┘
```

**링크 바구니 → 다른 폴더**로 옮기면 `정리 완료!` 알림이 뜹니다. 바구니가 비면 `🧺 바구니 클리어`도 표시됩니다.

### 여러 개 선택 · 삭제

| 동작 | 설명 |
|------|------|
| 카드 **클릭** | 선택 / 해제 |
| 빈 곳 **드래그** | 여러 장 한 번에 선택 |
| 선택 후 **드래그** | 여러 링크를 한 폴더로 이동 |
| **×** | 삭제 (토스트 **되돌리기**로 복구 가능) |
| **✎** | URL·제목 수정 |
| **현재 페이지 삭제** | 화면에 보이는 12개만 일괄 삭제 |

## 검색

| | 위치 | 범위 |
|---|------|------|
| **전역 검색** | 헤더 **🔍** | 앱 **전체** |
| **폴더 검색** | 오른쪽 목록 위 | **지금 폴더**만 |

- 전역 검색 결과를 누르면 해당 폴더로 이동합니다.
- **폴더를 바꾸면** 오른쪽 검색어는 자동으로 비워집니다.
- **여러 폴더**를 같은 단어로 찾을 때는 **🔍 전역 검색**을 쓰세요.

검색 대상: **제목 · 채널명 · URL**

## 백업 · 테마

**백업** — 헤더 **⬇** 으로 JSON 파일 저장, **⬆** 으로 다시 불러옵니다. (다른 PC·재설치 대비)

**정렬** — 최근 추가순 / 이름순 · 한 페이지 **12개**

- **최근 추가순** — 등록 시각(`createdAt`) **내림차순** (최신이 위)
- **이름순** — 링크 **제목**(`title`) 기준 한국어 사전순 (`localeCompare`). 기호·숫자가 한글보다 앞에 올 수 있음

**테마** — **🌙** 다크 → **☀️** 라이트 → **✨** 네온 (클릭할 때마다 바뀜, 다음에도 유지)

## 자주 묻는 것

**Q. 로그인이 필요한가요?**  
A. 아닙니다. 각 사이트는 열 때 직접 로그인합니다. 링크함은 로그인 정보를 저장하지 않습니다.

**Q. 카드 테두리가 점선인 이유는?**  
A. **수동 카드**입니다. + 버튼에서 「제목 수동 입력」으로 만든 경우입니다. 썸네일이 있는 카드는 URL에서 자동으로 정보를 가져온 **자동 카드**입니다.

**Q. 모바일에서 쓸 수 있나요?**  
A. **PC·넓은 브라우저 창**을 권장합니다. 모바일 전용 화면은 없습니다.
