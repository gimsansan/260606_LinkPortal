# 링크함 — 사용자 가이드

**링크함**은 웹 링크를 폴더로 정리하고, 더블클릭 한 번으로 사이트를 여는 **데스크톱용 PWA**입니다.  
데이터는 이 기기(브라우저)에만 저장됩니다. 로그인·미디어 추출 없이 **접속만** 돕습니다.

## 2. 처음 시작

1. 앱을 열면 **`🧺 링크 바구니`** 가 자동 선택됩니다.
2. 링크가 없으면 *「아직 저장된 링크가 없어요」* 가 보입니다.
3. **+ 버튼** 또는 **드래그 앤 드롭**으로 링크를 넣어 보세요.

> **링크 바구니** — 새로 모은 링크를 잠깐 두는 곳. 나중에 다른 폴더로 옮기며 정리합니다.

## 3. 링크 추가하기

### + 버튼으로 추가

1. 왼쪽에서 **넣을 폴더** 선택
2. 오른쪽 위 **+** 클릭
3. URL 입력 (`naver.com`처럼 `https://` 없이도 가능)
4. **추가**

**제목 수동 입력**을 켜면 썸네일 없이 제목만 직접 지정할 수 있습니다.

### 드래그 앤 드롭으로 추가

바탕화면 `.url` 파일, 브라우저 **주소창·탭**의 URL을 앱 **아무 곳**에 놓을 수 있습니다.  
→ 자세한 그림 설명은 **[4장](#4-️-드래그-앤-드롭으로-링크-추가하기)** 을 참고하세요.

| 드롭 대상 | 들어가는 폴더 |
|-----------|----------------|
| 폴더를 **먼저 선택**한 상태 | 선택한 폴더 |
| 폴더 **미선택** | **🧺 링크 바구니** (없으면 자동 생성) |

## 4. 🖱️ 드래그 앤 드롭으로 링크 추가하기

바탕화면의 **`.url` 바로가기**를 끌어다 놓기만 하면 링크가 추가됩니다.  
브라우저 **탭·주소창**에서 URL을 직접 끌어오는 것도 같습니다.

### Step 1 — 파일 선택

바탕화면에서 `.url` 파일을 고릅니다. **여러 개**를 한 번에 선택할 수 있습니다.

```
  🖥️ 바탕화면
 ┌─────────────────────┐
 │                     │
 │   📄 naver.url      │  ← Ctrl+클릭으로
 │   📄 google.url     │    여러 개 선택 가능
 │                     │
 └─────────────────────┘
```

### Step 2 — 앱 위로 끌어다 놓기

선택한 파일을 **링크함 창 아무 곳**으로 드래그합니다.

```
  🖥️ 바탕화면                           🌐 링크함
 ┌──────────┐                    ┌──────────────────────────┐
 │          │                    │  링크함  🔍       🌙     │
 │ 📄 naver │ ──── 드래그 ───▶  ├────────┬─────────────────┤
 │ 📄 google│                    │ 폴더   │ 🧺 링크 바구니  │
 │          │                    │ ├ 🧺   │                 │
 └──────────┘                    │ └ …    │   여기에 놓기!   │
                                 │        │       ⬇         │
                                 └────────┴─────────────────┘
```

드래그 중에는 화면 전체에 **반투명 오버레이**가 뜨고  
*「.url 파일 또는 링크를 놓으세요」* 안내가 표시됩니다.

> 💡 **특정 폴더**를 먼저 클릭해 둔 뒤 드롭하면, 그 폴더에 추가됩니다.  
> 폴더를 고르지 않았다면 **🧺 링크 바구니**에 들어갑니다.

### Step 3 — 카드 자동 생성

놓으면 URL 정보를 읽어 **카드가 자동으로 만들어지고**, 해당 폴더 화면으로 이동합니다.

```
  ✅ 완료!

  🧺 링크 바구니
 ┌──────────────────────────────────────────┐
 │  ┌─────────────┐   ┌─────────────────┐  │
 │  │ 🌐          │   │ 🔍              │  │
 │  │  NAVER      │   │  Google         │  │
 │  │  naver.com  │   │  google.com     │  │
 │  └─────────────┘   └─────────────────┘  │
 └──────────────────────────────────────────┘
     ↑ 썸네일·제목은 URL에서 자동 수집 (YouTube 등)
```

### 한눈에 보기

```
  📄 naver.url  ─┐
                  ├── 드래그 ──▶  🌐 링크함  ──▶  🃏 카드 자동 생성
  📄 google.url ─┘              (아무 곳)        + 해당 폴더로 이동
```

| 넣을 수 있는 것 | 예 |
|-----------------|-----|
| Windows `.url` 바로가기 | 바탕화면·탐색기에서 끌기 |
| 브라우저 URL | 주소창·탭에서 앱으로 끌기 |
| 여러 개 한 번에 | `.url` 여러 파일 또는 URL 여러 개 |

## 5. 링크 열기 · YouTube

| 동작 | 결과 |
|------|------|
| 카드 **더블클릭** | 링크 열기 |
| 선택 후 **Enter** | 링크 열기 |
| **YouTube** | 앱 **안에서** 재생 (오버레이) |
| **그 외** | **새 탭**에서 사이트 열기 |

**YouTube 추가 기능**

- 카드에 **▶** 표시
- **▶ 전체 재생** — 폴더 안 YouTube를 연속 재생 (기본: **최근 추가순**)
- **랜덤 재생** — 툴바 토글. 켜면 다음 곡·전체 재생이 **랜덤** 순서
- **자동 넘김** — 영상 종료 후 다음 곡 (툴바 토글)
- 재생 불가 영상 → 새 탭 fallback
- **×** 또는 바깥 클릭으로 플레이어 닫기

#### 재생 순서 (YouTube)

| 설정 | 다음 곡 · 전체 재생 순서 |
|------|--------------------------|
| **랜덤 재생 OFF** | **최근 추가순** (`createdAt` 내림차순) |
| **랜덤 재생 ON** | Fisher–Yates **랜덤** |
| **폴더 변경** | 랜덤 재생 **자동 OFF** (원본 순서로 리셋) |

**랜덤 재생 세부 동작**

- **OFF → ON** — 매번 **새로 섞음**. 재생 중이면 **지금 곡은 0번**에 두고 나머지만 섞음 (Spotify 방식)
- **ON → OFF** — **최근 추가순** 원본으로 복귀
- **전체 재생 + 랜덤 ON** — 전체를 섞은 뒤 **첫 곡**부터 재생
- **전체 재생 + 랜덤 OFF** — 최근 추가순 **첫 곡**부터 재생

> **목록 정렬과 무관** — 오른쪽 툴바의 「최근 추가순 / 이름순」은 **카드 표시**만 바꿉니다. YouTube 재생 순서에는 영향을 주지 않습니다.

## 6. 폴더 관리

| 하고 싶은 일 | 방법 |
|--------------|------|
| 폴더 보기 | 트리에서 **한 번 클릭** |
| 루트 폴더 추가 | 「폴더」 옆 **+** |
| 하위 폴더 추가 | **⋯** → **📁 하위 폴더 추가** |
| 이름 변경 | 폴더 **더블클릭** |
| 다른 위치로 이동 | **⋯** → **↗ 이동** |
| 삭제 | **⋯** → **❌ 삭제** (하위·링크 전부 삭제, 확인 창) |
| 접기 / 펼치기 | **▸ / ▾** |

기본 폴더 이름: `🧺 새 폴더` → 중복 시 `🧺 새 폴더 1`, `2` …

> 폴더는 **드래그로 옮길 수 없습니다.** ⋯ 메뉴의 **이동**만 사용합니다.

## 7. 링크 정리 · 드래그 이동

### 폴더로 옮기기

- 카드 **↗** → 이동할 폴더 선택
- 카드를 **왼쪽 트리의 폴더** 위에 **끌어다 놓기**
- **여러 장 선택** 후 한 번에 드래그 가능

**링크 바구니 → 다른 폴더** 로 옮기면 `정리 완료!` 토스트가 뜹니다. 바구니가 비면 `🧺 바구니 클리어`도 표시됩니다.

```
  오른쪽 카드              왼쪽 폴더 트리
 ┌────────┐
 │ NAVER  │ ──드래그──▶  🧺 새 폴더  ← 여기에 놓으면 이동
 └────────┘
```

### 카드 버튼 · 선택

| 버튼 / 동작 | 설명 |
|-------------|------|
| **×** | 삭제 → 토스트 **되돌리기** (약 5초) |
| **↗** | 폴더 이동 (모달) |
| **✎** | URL·제목 수정 |
| 카드 **클릭** | 선택 / 해제 |
| 빈 공간 **드래그** | 영역 선택 (다중) |
| 바깥 클릭 | 선택 해제 |
| **현재 페이지 삭제** | 보이는 12개만 일괄 삭제 |

## 8. 검색

| 종류 | 위치 | 범위 |
|------|------|------|
| **전역** | 헤더 **🔍** | 앱 전체 |
| **폴더** | 오른쪽 목록 검색창 | **현재 폴더**만 |

- 전역 결과 클릭 → 해당 **폴더로 이동**
- **폴더를 바꾸면** 오른쪽 검색어 **자동 초기화**
- **링크함** 클릭 → 홈 + **전역 검색** 초기화

검색 대상: **제목 · 채널명 · URL**

> 여러 폴더를 같은 단어로 찾을 때는 **전역 검색(🔍)** 을 쓰세요.

## 9. 백업 · 테마 · 기타

### 백업 · 복원

| 버튼 | 설명 |
|------|------|
| **⬇** | `linkportal-backup-날짜.json` 내보내기 |
| **⬆** | JSON 가져오기 (기존 데이터와 **합치기**) |

### 정렬 · 페이지

- **최근 추가순** — 등록 시각 내림차순 (기본)
- **이름순** — 링크 **제목** 한국어 사전순 (기호·숫자 → 한글 순). **재생 순서와 무관**
- 페이지당 **12개**, **‹ ›** 로 이동

### 테마

**🌙 다크** → **☀️ 라이트** → **✨ 네온** (헤더 버튼 클릭마다 순환, 다음 실행 시에도 유지)

### 카드 종류

| 모양 | 의미 |
|------|------|
| **썸네일** 있음 | URL에서 자동 수집 (**auto**) |
| **점선** 테두리 | 제목만 직접 입력 (**manual**) |

### 알아두면 좋은 점

- 로그인 정보는 **저장하지 않습니다**
- **데스크톱·넓은 창** 권장 (모바일 전용 UI 없음)
